# Architecture (data and engine)

```
data/raw (gitignored)  --ingest-->  clean.load_places  -->  network.build_network (seeded)  -->  milp.Model (LP text)  -->  HiGHS (highspy)
   Census Gazetteer 2026                join + ledger           SYNTHETIC network                 same text in browser            scenarios.package
   Census PEP sub-est2025                                                                                                         robustness.run_mc
                                                                                                           pipelines/publish  -->  site/public/data/*.json  (+ schema validation)
```
- No backend. The static site fetches `site/public/data/*.json`; live solves run in a Web Worker with highs@1.15.3 on the identical LP text built from `network.json` + `model.json` + the control values.
- **Single source of truth for the LP**: `analytics/milp.py::Model.lp_text`. `tests/parity/build_lp.mjs` is the reference JavaScript port (about 70 lines of builder) and must keep the hash identical; the site's TypeScript builder should be a straight port of it.
- **Artifact contracts**: `data/contracts/*.schema.json` generated by `pipelines/contracts.py`; TypeScript types are to be generated from them in the site phases.
- **Operational states for the browser solve** (contract for the site): initial (no solve run, preset shown, tagged `PRECOMPUTED · PYTHON HiGHS`), loading (worker + wasm), ready (`SOLVED IN BROWSER · HiGHS`), infeasible (status `Infeasible`, offer the elastic relaxation which sets `relax = true` and re-solves), time limit / error (fall back to the preset with the same params if there is one, else show error with retry), reset (default params). Solve status strings are pinned: `Optimal`, `Infeasible`.
- **Determinism**: sorted-key compact JSON, `generated_at` = first Census retrieval time from the manifest, seeded numpy generators, HiGHS `threads 1`, `random_seed 0`; a test re-runs the whole publish step and compares bytes.
- **Resource use**: peak resident memory 282 MB (measured with /usr/bin/time -l on the publish step), one HiGHS thread; full pipeline about 15 to 20 s after the one-time 8.7 MB download.
